* **Критерий «сидели вместе»:** два сотрудника находились в комнате в один и тот же календарный день на пересекающихся сменах (учтены дневные смены `12`, `11`, `8`, `16/8`, а также утренние/вечерние часы ночных смен `4/8`, которые пересекаются с дневными сменами в этой же комнате).
